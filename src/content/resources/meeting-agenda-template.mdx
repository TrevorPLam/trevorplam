## Meeting Type Templates

### Weekly Team Meeting

**Focus**: Progress updates, roadblocks, coordination
**Duration**: 30-60 minutes
**Key Sections**:
- Wins and successes from previous week
- Priority goals for current week
- Resource needs and roadblocks
- Team announcements and updates

### Project Review Meeting

**Focus**: Project status, risks, decisions
**Duration**: 60-90 minutes
**Key Sections**:
- Project status against timeline and budget
- Risk assessment and mitigation
- Stakeholder updates and requirements
- Next phase planning and decisions

### Strategy Planning Meeting

**Focus**: Long-term planning, goal setting
**Duration**: 2-4 hours
**Key Sections**:
- Current state analysis
- Future vision and goals
- Strategic options and evaluation
- Implementation planning and resource allocation

### Decision-Making Meeting

**Focus**: Specific decision, options evaluation
**Duration**: 60 minutes
**Key Sections**:
- Problem definition and background
- Option presentation and analysis
- Criteria-based evaluation
- Decision documentation and communication

## Best Practices

### Before the Meeting

**Send Agenda Early**:
- Distribute agenda at least 24 hours in advance
- Include all required materials and pre-reading
- Specify preparation expectations
- Request confirmation of attendance

**Room/Technology Setup**:
- Test audio/video equipment
- Prepare presentation materials
- Arrange room for optimal participation
- Have backup technology ready

**Participant Preparation**:
- Review all pre-meeting materials
- Prepare talking points for agenda items
- Note questions and concerns in advance
- Coordinate with other presenters

### During the Meeting

**Time Management**:
- Start and end on time
- Use timekeeper for agenda items
- Be prepared to table off-topic discussions
- Maintain focus on objectives

**Participation Management**:
- Ensure all voices are heard
- Manage dominant personalities
- Keep discussions constructive
- Use parking lot for off-topic items

**Documentation**:
- Assign note-taker in advance
- Capture key decisions and action items
- Document attendees and apologies
- Record next meeting date if needed

### After the Meeting

**Immediate Follow-up**:
- Send meeting notes within 24 hours
- Distribute action item assignments
- Schedule follow-up meetings if needed
- Update project documentation

**Action Item Tracking**:
- Enter action items into tracking system
- Set reminders for due dates
- Monitor progress on assignments
- Report completion to stakeholders

## Common Meeting Problems

### Problem 1: No Clear Objectives
**Symptoms**: Meandering discussion, unclear purpose
**Solutions**:
- Always define specific objectives in agenda
- Start meeting by restating objectives
- Refer back to objectives when discussion strays
- End meeting by confirming objectives were met

### Problem 2: Poor Time Management
**Symptoms**: Running over time, rushing through items
**Solutions**:
- Allocate realistic time per agenda item
- Use visible timer or timekeeper
- Be prepared to prioritize or defer items
- Start and end on time regardless

### Problem 3: No Follow-up
**Symptoms**: Decisions not implemented, action items forgotten
**Solutions**:
- Assign specific owners and due dates
- Document and distribute action items immediately
- Set up tracking system for follow-up
- Review action items at next meeting

### Problem 4: Unprepared Participants
**Symptoms**: Lack of meaningful contribution, delays
**Solutions**:
- Send agenda and materials well in advance
- Specify preparation requirements clearly
- Include pre-meeting questions for thought
- Reschedule if key people unprepared

## Virtual Meeting Considerations

### Technology Setup

**Platform Preparation**:
- Test meeting platform functionality
- Prepare backup connection method
- Set up waiting room if appropriate
- Configure recording if needed

**Participant Guidelines**:
- Mute when not speaking
- Use video when possible
- Ensure good lighting and background
- Minimize distractions and multitasking

**Engagement Techniques**:
- Use polls and breakout rooms
- Ask for input via chat or reactions
- Call on specific people for input
- Take regular breaks for longer meetings
